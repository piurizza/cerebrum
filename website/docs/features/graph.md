# Graph

**Graph** draws the whole vault: each note is a dot, each link a line between
two dots. Click a dot to open its note.

![The link graph of the demo vault](../assets/screenshots/graph.webp)

- Drag to move around, scroll or pinch to zoom.
- Notes that link to each other a lot pull together, so related notes form
  clusters.
- A link to a note that doesn't exist yet shows as a ghost dot, drawn
  differently, so you can see what's still to write.

Both markdown links and `[[wikilinks]]` count; see [Links](links.md).
