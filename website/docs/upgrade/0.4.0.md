## New

- **Wikilinks.** Cerebrum reads Obsidian-style `[[wikilinks]]`, including
  aliases, headings and image embeds, in the preview, the graph and backlinks,
  and keeps them working when notes are renamed. Set
  `CEREBRUM_LINK_FORMAT=wikilink` to have the editor and AI assistants write
  them too. See [Links](../features/links.md).
