# 0.5.0

## Before you upgrade

**Notes in folders whose name starts with a dot are no longer notes.**
Cerebrum now ignores files and folders whose name starts with a dot, such as
`.trash/`, `.obsidian/` or `.git/`. Notes in them disappear from the note
list, search, the graph, tasks and MCP. The files stay on disk, untouched.

If you keep notes you use in such a folder, rename the folder before
upgrading. A note can still be opened by its exact path, and moving a note
into `.trash/` is now a way to hide it.

**Daily-note and template folders can't be hidden folders.** If
`CEREBRUM_DAILY_NOTE_FOLDER` or `CEREBRUM_TEMPLATES_FOLDER` starts with a
dot, Cerebrum refuses to start. Choose a folder without one.

**The first start rebuilds the index.** Cerebrum re-reads every note once, so
that first start takes a little longer on a large vault. Nothing in the notes
changes.

**Set `CEREBRUM_TIMEZONE` if you use AI assistants with tasks.** The MCP task
tools use today in that time zone when an assistant gives no date; unset, they
use the server's, which is UTC in Docker. For example
`CEREBRUM_TIMEZONE=Europe/Rome`. See the
[configuration reference](../reference/configuration.md).

**API clients:** a note now has a `version` field. Send it back in an
`X-Base-Version` header on `PUT /api/notes/{path}` and the save is refused with
412 if the note changed since; `X-Create-Only: 1` refuses it if the note
already exists. Saves without these headers work as before. See the
[REST API](../reference/rest-api.md).

## New

- **A working task list.** Add tasks to today's note, tick them off with
  **Undo**, filter by tag, folder and words, and see what you finished in the
  last two weeks. Ticking writes a `✅ 2026-10-26` date, as the Obsidian Tasks
  plugin does. A task opens its note at its line, and a note's preview ticks
  tasks too. See [Tasks](../features/tasks.md).
- **AI assistants can list, add and tick tasks** with `list-tasks`, `add-task`
  and `set-task-done`. See [MCP tools](../agents/mcp-tools.md).
- **Tags in the search box.** Type `#` to pick tags, `-#` to leave one out;
  this replaces the wall of tag buttons in the sidebar. See
  [Tags and search](../features/tags-and-search.md).
- **Tag front page.** The front page browses the vault by tag. See
  [Tag front page](../features/tag-front-page.md).
- **Sign in with an identity provider** such as Keycloak, Authentik, Pocket ID
  or Google. See [Sign in with an identity provider](../running/identity-provider.md).
- **Read-only vault mode** for a vault another tool owns. See
  [Read-only vault](../running/read-only-and-second-instance.md).
- **Cerebrum's state can live outside the vault,** with
  `CEREBRUM_INDEX_PATH` and `CEREBRUM_AUTH_DB_PATH`. Move an existing accounts
  database first, as described in
  [Move Cerebrum's state out of the vault](../running/read-only-and-second-instance.md#move-cerebrums-state-out-of-the-vault).
- **A Docker install's `.env` can now set** `AUTH_COOKIE_SECURE`, the session
  lengths, `MCP_ENABLED`, `MAX_ATTACHMENT_SIZE_BYTES` and the `WATCHER_*`
  settings. Before, they had no effect there. Raising
  `MAX_ATTACHMENT_SIZE_BYTES` now raises the bundled web server's limit too.
- **`LOG_LEVEL` works.** Before, it was ignored and the backend's own
  messages, several of them about sign-in problems, were never logged. See the
  [configuration reference](../reference/configuration.md).
- **The desktop app can switch servers** with **Cerebrum > Change server…** in
  its menu bar. See [Desktop app](../install/desktop.md#connect-to-a-different-server).
- **This documentation site.**

## Fixed

- Saving a note no longer overwrites changes made to it elsewhere since you
  opened it. Changes to other lines are merged in; when both touched the same
  lines, Cerebrum asks whether to reload or keep your version.
- **Today** no longer overwrites a daily note created on another device a
  moment before.
- ++ctrl+s++ right after opening a note saves it.
- Links and images whose file names have spaces are followed, written as
  `[x](My%20Note.md)` or `[x](<My Note.md>)`. Notes imported from Notion or
  Joplin arrive linked. See [Links](../features/links.md).
- Sign-in with an identity provider works behind Tailscale serve or a reverse
  proxy. See [HTTPS](../running/https.md).
- A Cerebrum no longer accepts sign-in tokens issued by another Cerebrum that
  shares its `AUTH_JWT_SECRET`, such as a read-only second instance. Nobody
  is signed out by the upgrade.
- The last admin who can sign in with a password can't be deactivated, so an
  identity-provider outage can't lock everyone out.
- Dependencies with known vulnerabilities were updated, among them the
  sanitizer used for diagrams.
