# Tag front page

Cerebrum's front page lists every tag in the vault with its note count. Nested
tags sit on a line under their parent. Tap tags to select them, and the notes
that carry all of them are listed, most recently updated first.

![The front page with the cooking tag selected](../assets/screenshots/tag-front-page.webp)

- **Filter tags** narrows a long list.
- Once a tag is selected, the counts show what picking another would leave,
  and tags that would leave nothing are dimmed.
- **Clear** removes the selection.

The selection is the same one as the chips in the search box, so it follows
you into a note and back. It is forgotten when you reload.

On a phone, the first pick folds the tag list away to make room for the
results; **Show all tags** brings it back.

To leave a tag out (`-#tag`) or combine tags with words, use the
[search box](tags-and-search.md#filtering-by-tag).
