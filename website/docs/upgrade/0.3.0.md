# 0.3.0

Released 2026-10-16.

## Before you upgrade

Two defaults changed. New installs with the install script aren't affected;
for an existing install, check `.env` before running `docker compose up -d`.

**The ports moved from 8080 and 8443 to 7811 and 7812.** To keep your old
address, set:

```sh
CEREBRUM_PORT=8080
CEREBRUM_HTTPS_PORT=8443
```

If Cerebrum is installed on a phone, keep the old HTTPS port: the installed
app and its offline copy belong to that exact address, port included.

**The ports now answer on the server only.** If you open Cerebrum from other
devices directly, without Tailscale or a proxy in between, set
`CEREBRUM_BIND_ADDRESS=0.0.0.0`. See [Security](../running/security.md) for
what that opens up.

## New

- **The install script**: one command installs Cerebrum on Linux or macOS,
  x86_64 or arm64, without cloning the repository. See
  [Install with the script](../install/docker.md).
- **The desktop app connects on its own** to a server on the same computer.
