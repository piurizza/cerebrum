# 0.1.0

Released 2026-10-16. The first release.

## Installing

There is nothing to upgrade from. Install by hand with the published images,
as in [Install by hand](../install/by-hand.md). The install script arrived
in [0.3.0](0.3.0.md).

## What it includes

- Notes as markdown files, with a folder tree, a preview, link-aware rename,
  move and delete, and created and updated times.
- Markdown links with a `[[` picker, backlinks, and a link graph with ghost
  nodes for links to missing notes.
- Full-text search and tag filters.
- Daily notes, templates, and a task list across the vault.
- Pasted images, and mermaid diagrams.
- Accounts with invites, personal API tokens, and an MCP server for AI
  assistants.
- Changes made outside Cerebrum picked up while it runs, renames included.
- A phone layout, an installable phone app, and offline reading.
- HTTPS with a self-signed certificate.
- A Linux desktop app.
- Prebuilt images for x86_64 and arm64.
